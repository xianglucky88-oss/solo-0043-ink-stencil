# 墨版 · 矢量遮罩合成校样

按局部轮廓、遮罩相交和混色逐像素生成画面；在透明背景上检查画面、像素与图层，冻结并下载 PNG。

## 启动

需要 Node.js 20 或更新版本，无需安装第三方依赖。

```sh
npm start
```

浏览器打开 `http://127.0.0.1:8742`。项目只监听本机回环地址；用 `PORT` 可换端口。`MEDIA_HOME` 可指定数据目录，默认 `.local/`，不进 Git。

## 校样

载入样例后用键盘方向键检查邻接像素，再切换采样数或画布底色对照。

可以导入 JSON，或者在「源文档」区域编辑。获取可导入样例：`curl -s http://127.0.0.1:8742/api/demo | node -e 'process.stdin.on("data",c=>s+=c).on("end",()=>console.log(JSON.stringify(JSON.parse(s).document,null,2)));let s=""'`。
更新校样只计算不落盘；冻结会写入版本库，下载原始 `.png` 资产。可在「冻结版本」中复取已保存版本。

## 分幅 PNG 套件

校样通过并冻结后，印制方可直接从选中的冻结版本下单分幅套件，无需打开工作草稿：在「分幅 PNG 套件」面板选择成品框（整数设计像素、正宽高）、四边等宽的非负整数出血和 1 或 2 倍原生像素倍率。也可直接调用接口：

```sh
curl -s http://127.0.0.1:8742/api/kits \
  -H 'Content-Type: application/json' \
  -d '{"version":"<冻结版本标识>","trim":{"x":0,"y":0,"w":400,"h":236},"bleed":10,"scale":2}'
```

返回的清单标明成品框在整幅输出中的位置，以及每片的左上坐标、实际尺寸和下载链接；每片最长边不超过 512 像素。两倍件按原生分辨率重新栅格化，不是一倍图放大。计算量受单次校样同一预算约束，按整幅输出像素、冻结版本采样设置和图层数核算。相同冻结版本、成品框、出血和倍率的重复或并发请求只栅格化一次并返回同一链接；交付后即使草稿修改或服务重启，凭链接取回的仍是当时的套件字节。
